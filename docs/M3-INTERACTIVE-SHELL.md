# M3 — Interactive Shell

Firmware version: 0.3.0

Scope:
- HOME / INPUT / OUTPUT / SYSTEM navigation
- capacitive touch navigation with visual feedback
- SYSTEM: software version, manual update status, reset settings
- NVS persistence via prisma_platform
- persisted brightness value and last normal UI view
- diagnostics: display, touch, firmware, uptime, free heap, brightness
- no Wi-Fi, media playback or OTA in this milestone

Hardware baseline remains the validated Waveshare ESP32-S3-Touch-LCD-1.54 BSP from M1/M2.
