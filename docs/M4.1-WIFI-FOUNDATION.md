# M4.1 — Wi-Fi Connectivity Foundation

Scope:
- ESP32-S3 Wi-Fi STA using saved credentials.
- NVS persistence for SSID/password.
- Automatic fallback setup AP: `PRISMA-PI-SETUP`.
- Setup endpoint at `http://192.168.4.1/setup` while fallback AP is active.
- Minimal network status API at `/api/v1/network/status`.
- Configure endpoint at `/api/v1/network/configure`.
- Forget/reset endpoint at `/api/v1/network/reset`.
- Network failure must never stop the local appliance UI.

This milestone intentionally does not yet implement the final `/` synthesizer UI, `/admin`, WebSocket synchronization, or media streaming. Those layers build on this network foundation.
